# Малевич

Десктопное приложение кальянной: ведение кальянов, полка вкусов и история заявок. Данные остаются на компьютере, входа нет.

## Скачать и запустить на Windows

Скачайте в одну папку на компьютере цельный архив и два файла рядом с ним:

- `download/Malevich-windows.zip` — внутри одна папка `Малевич` с `Малевич.exe` и остальными файлами Electron, включая `ffmpeg.dll`
- `download/SHA256.txt` — первая строка, `ZIP`, это контрольная сумма архива
- `download/ЗАПУСК.bat`

Дважды щёлкните **ЗАПУСК.bat**. Скрипт проверит сумму архива, распакует его и откроет `Малевич\Малевич.exe`. В следующий раз запускайте уже этот файл. Остальные файлы в папке `Малевич` не удаляйте: без них окно не откроется.

Windows SmartScreen показывает «неизвестный издатель», потому что у сборки нет платного сертификата подписи кода. Это проверка подписи, а не отдельный вердикт антивируса: файл собран из этого репозитория. Нажмите «Подробнее», затем «Выполнить в любом случае».

Три раздела в одном окне:

1. **Ведение кальянов** — карточки таймеров со вкусом, ближайший кальян слева сверху, столы из схемы зала и завершение смены.
2. **Полка** — визуал слева, чипсы брендов со счётчиками закончившихся вкусов, перенос карточек как в Trello, выгрузка заявки в Excel и копирование текста.
3. **История** — заявки свёрнуто и развёрнуто, топ вкусов, бренды, среднее время курения по факту, выгрузка аналитики.

Интерфейс тёмный и собран на токенах [inflavo.ru](https://inflavo.ru/): фон `#141414`, карточки `#232323`, акцент `#856353`, шрифт Roboto, радиус `0.45rem`.

## Запуск

```bash
npm install
npm run dev
```

Откроется окно Electron. Для проверки интерфейса в браузере, без окна Electron:

```bash
npm run dev:web
```

Адрес: http://127.0.0.1:43127

В браузере данные пишутся в `localStorage` этого окна. В Electron — в JSON в каталоге данных пользователя (`malewich.json`), план зала — JPEG рядом, в `plans`. Резервная копия снимается каждые 15 минут и при закрытии. Восстановление — в настройках.

## Сборка для Windows

```bash
npm run dist:win
```

Команда собирает распакованную папку `dist/win-unpacked` с `Малевич.exe`. Инсталлятора нет. `ffmpeg.dll` и остальные файлы Electron остаются в папке: без `ffmpeg.dll` окно на Windows не открывается. Рядом лежит `КАК-ЗАПУСТИТЬ.txt`.

## Горячие клавиши

- Пробел — зафиксировать реакцию на самый ранний алерт
- Стрелки влево и вправо — разделы

Пробел и стрелки не срабатывают, пока курсор в поле ввода. Пробел на кнопке остаётся нажатием этой кнопки.

## Проверки

```bash
npm test
npm run typecheck
```

Лимит полки — 500 вкусов. Напоминание о заявке настраивается: раз в неделю или в конце смены.
