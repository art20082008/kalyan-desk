# Малевич

Десктопное приложение кальянной: ведение кальянов, полка вкусов и история заявок. Данные остаются на компьютере, входа нет.

Три раздела в одном окне:

1. **Ведение кальянов** — карточки таймеров, свои алерты, прогрев, JPEG-план зала и несколько кальянов на одном столе.
2. **Полка** — визуал слева, чипсы брендов со счётчиками закончившихся вкусов, перенос карточек как в Trello, выгрузка заявки в Excel и копирование текста.
3. **История** — заявки свёрнуто и развёрнуто, топ вкусов, бренды, среднее время курения по факту, выгрузка аналитики.

Интерфейс тёмный и собран на токенах [inflavo.ru](https://inflavo.ru/): фон `#141414`, карточки `#232323`, акцент `#856353`, шрифт Roboto, радиус `0.45rem`.

## Запуск

```bash
npm install
npm run dev
```

Откроется окно Electron. Для проверки интерфейса в браузере, без окна Electron:

```bash
npm run dev:web
```

Адрес: http://127.0.0.1:43127

В браузере данные пишутся в `localStorage` этого окна. В Electron — в JSON в каталоге данных пользователя (`malewich.json`), план зала — JPEG рядом, в `plans`. Резервная копия снимается каждые 15 минут и при закрытии. Восстановление — в настройках.

## Сборка для Windows

```bash
npm run dist:win
```

Установщик появится в `release/`. Команду нужно запускать на Windows или в окружении с инструментами electron-builder для NSIS.

## Горячие клавиши

- Пробел — зафиксировать реакцию на самый ранний алерт
- Ctrl+S — выгрузить заявку в Excel
- Ctrl+C — скопировать текст заявки
- Esc — закрыть модалку
- Стрелки влево и вправо — разделы

Пробел и Ctrl+C не срабатывают, пока курсор в поле ввода.

## Проверки

```bash
npm test
npm run typecheck
```

Лимит полки — 500 вкусов. Напоминание о заявке настраивается: раз в неделю или в конце смены.
